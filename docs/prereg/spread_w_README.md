# Test of W: which document says what, and what is superseded

The frozen documents are never edited. Where a later one corrects an earlier one, this index says so. Read them in this
order.

| Document | What it is | Still stands | Superseded in it |
|---|---|---|---|
| `spread_eval_prereg.md`, `spread_eval_results.md` | The first test, G against H, 1 July to 10 October 2026, and its result | All of it. G beat H by 1.81 and missed the slice condition on holidays and the sunniest days | Nothing |
| `spread_w_prereg.md` | Design record of W and the first plan for its test | W itself, the window, the single read, the gain rule, the slices, the six stop conditions | Two decisions (now three, amendment 1). "The French refetch is not yet specified" (it is, `spread_w_refetch_spec.md`). The section "Why the first model failed, in short" and every reading of slow adaptation as the cause (amendment 1, section 5). The diagnosis was unreviewed when it was written (reviewed since, amendment 1, section 9). The table of variants is incomplete (amendment 1, section 5) |
| `spread_w_amendment_1.md` | The matched French-only comparator HW as the primary test, three decisions at 1 - 0.05/3, the diagnosis restated, provenance classes | All of that | The sentences "the redesign does nothing for the French-only model" and "the gain exists only when the German block is present"; "a failure of decision 3 would not be surprising" (amendment 2, section 3). The scoring code hash (the report gained the availability table, amendment 2) |
| `spread_w_refetch_spec.md` | Input by input: what can be recovered as of 10:05 Paris, how missing and revised values are handled | All of it for rebuilt days | For saved days, rule 3 (no fill) is narrowed by amendment 5 to allow the coupled German price of an hour before D from a second source. Amendment 2 adds how the January report shows it |
| `spread_w_amendment_2.md` | The morning logger, the January availability report, corrected wording, what has been reviewed and what has not | All of that | The logger's code hash and its self-test criterion (amendment 3) |
| `spread_w_amendment_3.md` | Forecasts are machine-dependent at about 2 EUR/MWh an hour; what that means for saved and rebuilt days and for reading any result near a threshold | All of that | The logger's code hash (amendment 4). The sentence that the price of D-1 was present in all 41 production windows saved by 10:05: those windows blend both German auctions, so it did not show that the coupled price was there (amendment 4) |
| `spread_w_amendment_4.md` | After the first unattended morning: the three fetches run side by side, a missing price of D-1 no longer postpones the record, the scramble check has a tolerance of 1e-9 | The three changes | Five sentences and the code hash, listed in the review document. It also supersedes, without naming them, amendment 3's sentences that the self-test requires identical inputs under the scramble and that a missing spread of yesterday postpones the record |
| `spread_w_amendment_4_review.md` | The independent review of amendment 4, the fixes it led to, and the sentences it supersedes | All of that | The code hash it prints (c0caa5f0...): a second look by the same reviewer found a small race in the side-by-side fetch, which was closed. The build to install has code hash 5bc3b094db2157a673a43e3adc30ea5f84717170d20cfe1a8a6ec614451127f3, recorded in `docs/experiments.md`. Its sentence that a given-up fetch's files 'carry the stamp of the run' holds for the German files; the French window carries its own write time |
| `spread_w_amendment_5.md` | After the second unattended morning: a second source (energy-charts.info) for the coupled German price, used only for hours before D that ENTSO-E lacks and only on a morning when the two agree; what the probe of 2026-11-21 showed | The change and its four conditions | Rule 3 of `spread_w_refetch_spec.md` (no fill) is narrowed for saved days to this one case and stands for rebuilt days. Two rules of amendment 4 are narrowed: a failed German price request to ENTSO-E postpones only if the German price of the eve is then missing, and a failed request to the second source postpones only in the same case. The header of the logger now says four fetches |
| `spread_w_amendment_5_review.md` | The independent review of amendment 5 and its code, and the code hash of the build to install | All of that | Nothing |

Project notes outside the repository: the note "Spread forecast: what the failed test showed, the new model W, and how it
will be judged" has had three versions. Only the latest is current. An earlier version said the cause was found, that there
were two tests, that the refetch was unspecified and that the diagnosis was unreviewed. All four statements are superseded.
